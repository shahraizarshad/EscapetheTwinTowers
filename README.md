Escape The Twin Towers
Escape The Twin Towers is a 2D arcade-style aerial survival game developed in C++ using SFML. The game challenges players to pilot aircraft through an increasingly difficult environment filled with obstacles, enemy aircraft, weather hazards, and boss encounters. Players can collect coins, purchase upgrades, unlock new skins, and utilize special abilities to survive for as long as possible while achieving the highest score.

The game features both single-player and two-player modes, allowing players to either take on the challenge alone or cooperate with a partner. As players progress, they encounter dynamic enemy behavior, power-ups, boss battles, environmental effects, and multiple visual themes that keep gameplay engaging and varied.

Development of the project was divided among three team members based on different aspects of the game. Fatima Khan (26L-0731) was responsible for the display and user interface components of the project. Her contributions included the menu system, heads-up display (HUD), shop interface, scoreboard screens, pause menu, game over screens, and the overall presentation of information to the player.

Shahraiz Arshad (26L-0678) worked on the visual design and graphical aspects of the game. His responsibilities included creating aircraft and enemy visuals, obstacle rendering, environmental graphics, background scenes, particle-based visual effects, and the shape-based drawing system used throughout the project.

Abdullah Zahid (26L-0685) was responsible for the gameplay systems and game mechanics. His work included implementing player controls, collision detection, enemy behavior, combat mechanics, power-up functionality, boss encounters, scoring systems, and the overall game logic that drives player interaction.

The project was developed using C++ and SFML, with additional functionality provided through file handling for save data and high-score management. The game combines action-oriented gameplay with a progression system that rewards players through upgrades, unlockable content, and competitive score tracking.

Build Requirements
C++17 or later
SFML 3.0
Windows or Linux operating system
How to Run
Install SFML on your system.
Clone the repository.
Build the project using a C++ compiler that supports C++17.
Ensure all game assets are placed in the appropriate assets directory.
Run the executable to start the game.
